# Проект "Банковский виджет и обработка данных"

## Описание проекта
Этот проект представляет собой наборутилитарных модулей на Python для обработки и фильтрации банковских данных (транзакций), маскирования конфиденциальной информации (номеров карт и счетов) и форматирования дат. Он закладывает основу для логики личного кабинета пользователя.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd название_репозитория
   ```

2. Убедитесь, что у вас установлен Python версии 3.10 или выше.

3. (Опционально) Установите зависимости для тестирования:
   ```bash
   pip install pytest
   ```

## Использование модулей и функций

### 1. Модуль `masks`
Содержит базовые функции скрытия персональных данных.

* **`get_mask_card_number(card_number)`**: Маскирует номер карты. Возвращает строку в формате `XXXX XX** **** XXXX`.
* **`get_mask_account(account_number)`**: Маскирует номер счета. Возвращает последние 4 цифры в формате `**XXXX`.

### 2. Модуль `widget`
Содержит высокоуровневые функции для подготовки данных к отображению в интерфейсе.

* **`mask_account_card(info_string)`**: Автоматически определяет тип платежного средства (карта или счет) и маскирует номер, сохраняя текстовое название.
* **`get_date(date_string)`**: Преобразует строку даты из формата ISO (например, `"2024-03-11T02:26:18"`) в привычный формат `"ДД.ММ.ГГГГ"`.

**Примеры работы:**
```python
from src.widget import get_date, mask_account_card

# Маскирование карты
print(mask_account_card("Visa Platinum 7000792289606361"))  
# Вывод: Visa Platinum 7000 79** **** 6361

# Маскирование счета
print(mask_account_card("Счет 73654108430135874305"))  
# Вывод: Счет **4305

# Форматирование даты
print(get_date("2024-03-11T02:26:18.671407"))  
# Вывод: 11.03.2024
```

### 3. Модуль `processing`
Предоставляет инструменты для аналитики и фильтрации списков транзакций.

* **`filter_by_state(data, state_value)`**: Фильтрует список словарей по статусу операции (`'EXECUTED'` по умолчанию).
* **`sort_by_date(data, reverse)`**: Сортирует список словарей по дате операции (по умолчанию — от самых свежих к самым старым).

**Примеры работы:**
```python
from src.processing import filter_by_state, sort_by_date

transactions = [
    {'id': 1, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58'},
    {'id': 2, 'state': 'CANCELED', 'date': '2019-07-03T18:35:29'},
]

# Фильтрация только выполненных транзакций
print(filter_by_state(transactions)) 

# Сортировка транзакций по дате
print(sort_by_date(transactions, reverse=True))
```

### 5. Модуль `utils`

Содержит утилиты для загрузки данных о транзакциях из файлов.

* **`load_transactions(file_path)`**: Загружает список транзакций из файла. Поддерживает три формата:
  * **JSON** (`.json`) — ожидает список словарей;
  * **CSV** (`.csv`) — считывается с помощью `pandas`;
  * **Excel** (`.xlsx`) — считывается с помощью `pandas` и `openpyxl`.

  Если файл не найден, пуст, содержит некорректные данные или имеет неподдерживаемое расширение, функция возвращает пустой список `[]`. Все действия и ошибки логируются в папку `logs/`.

**Пример использования:**
```python
from src.utils import load_transactions

# Загрузка JSON (как и раньше)
json_data = load_transactions("data/operations.json")

# Загрузка CSV
csv_data = load_transactions("data/transactions.csv")

# Загрузка Excel
xlsx_data = load_transactions("data/transactions_excel.xlsx")

print(f"Загружено из CSV: {len(csv_data)} транзакций")
```

### 6. Модуль `external_api`

Содержит функции для конвертации валют через внешний сервис **Exchange Rates Data API** (apilayer).

* **`get_exchange_rate(from_currency, to_currency)`**: Делает запрос к API и возвращает текущий курс конвертации (тип `float`). Требует наличия API-ключа в переменной окружения.
* **`convert_transaction_to_rub(transaction)`**: Принимает словарь с данными транзакции и возвращает её сумму в рублях.
  * Для транзакций в **RUB** сумма возвращается сразу, без запросов к API.
  * Для транзакций в **USD** или **EUR** сумма конвертируется по текущему курсу через `get_exchange_rate`.
  * Для остальных валют выбрасывается `ValueError`.

**Настройка окружения:**
Для работы модуля нужен API-ключ. Создайте в корне проекта файл `.env` и добавьте в него:
```
EXCHANGE_RATES_API_KEY=ваш_ключ_от_apilayer
```
*Шаблон для файла `.env` находится в `.env.example`. Сам файл `.env` добавлен в `.gitignore` и не попадает в репозиторий.*

**Пример использования:**
```python
from src.external_api import convert_transaction_to_rub

transaction = {
    "operationAmount": {
        "amount": "100.00",
        "currency": {"name": "USD", "code": "USD"}
    }
}

rub_amount = convert_transaction_to_rub(transaction)
print(f"Сумма в рублях: {rub_amount}")
```

### 7. Логирование

Для модулей `masks` и `utils` реализовано логирование с помощью стандартной библиотеки `logging`.
* Логи записываются в папку `logs/` в корне проекта (файлы `masks.log` и `utils.log`).
* Формат записи: `Время - Имя модуля - Уровень - Сообщение`.
* Логи **перезаписываются** при каждом новом запуске приложения.
* Папка `logs/` добавлена в `.gitignore`, так как содержит только временные данные.


### 8. Модуль `search`

Содержит функции для поиска и аналитики по описаниям транзакций.

* **`process_bank_search(data, search)`**: Принимает список транзакций и строку поиска. Возвращает список транзакций, в описании которых встречается искомая строка (поиск не зависит от регистра). Для поиска используется библиотека `re`.
* **`process_bank_operations(data, categories)`**: Принимает список транзакций и список категорий. Возвращает словарь, где ключи — это названия категорий, а значения — количество операций в каждой категории (категория берётся из поля `description`).

**Примеры работы:**
```python
from src.search import process_bank_search, process_bank_operations

# Поиск по слову (регистр не важен)
found = process_bank_search(transactions, "перевод")
print(f"Найдено операций: {len(found)}")

# Подсчет операций по категориям
categories = ["Перевод организации", "Перевод с карты на карту"]
counts = process_bank_operations(transactions, categories)
print(counts) 
# Вывод: {'Перевод организации': 2, 'Перевод с карты на карту': 1}
```

### 9. Главный модуль программы (`main`)

Модуль `src/main.py` связывает все части проекта в единую программу с интерфейсом командной строки. 

При запуске программа приветствует пользователя и предлагает:
1. Выбрать формат файла с данными (JSON, CSV или XLSX).
2. Отфильтровать операции по статусу (`EXECUTED`, `CANCELED`, `PENDING`).
3. Отсортировать операции по дате (по возрастанию или убыванию).
4. Оставить только рублевые транзакции (опционально).
5. Отфильтровать операции по ключевому слову в описании (опционально).

В конце программа выводит красивый список найденных транзакций с замаскированными номерами карт/счетов, датами и суммами.

**Запуск программы:**
```bash
python -m src.main
```
